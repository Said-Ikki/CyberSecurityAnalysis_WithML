# CyberSecurityAnalysis_WithML

Main Source: https://www-sciencedirect-com.ezproxy.lakeheadu.ca/science/article/pii/S0167404824000178?via%3Dihub

Supplementary Source: https://www-sciencedirect-com.ezproxy.lakeheadu.ca/science/article/pii/S0167404823005710?via%3Dihub

Topic: ML Techniques (ANN and CNN) to Detect & Mitigate DDoS Attacks

Summary: 
- DDoS (Distributed Denial of Service) Attacks are a prevalent issue in Software-Defined Networks (SDNs)
- Current methods involve an over-reliance on rigid, predefined rules and attack signatures
- The main article uses CNNs along with various performance-boosting techniques to reach high efficacy in detecting DDoS attacks
- The supplementary article was able to achieve high efficacy on DDoS detection using ANNs
