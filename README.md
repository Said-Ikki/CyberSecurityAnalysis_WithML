# CyberSecurityAnalysis_WithML

Source: https://ieeexplore.ieee.org/document/11275030
Topic: Cyber Attack Detection in P2P Energy Trading Using Machine Learning
Summary: 
- P2P Energy Trading allow for power to be allocated between users depending on each user's needs
- This allows users who produce excess energy to trade it to those who would like to use the extra power
- Because it is all digital and on the blockchain, there are cybersecurity risks to be considered
- Machine Learning (ML) algorithms may help identify/detect potential cyber risks
